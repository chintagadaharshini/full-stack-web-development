# Full Stack Web Development Coursework

This repository organizes course observations, e-record PDFs, assignments, and the group project.

## Individual project: SkillSwap
SkillSwap is a student-to-student skill exchange board. Students can offer skills they know, request skills they want to learn, browse listings, search/filter by category, and save listings. The current milestone is a React frontend using localStorage. A backend can be added later if required by the course.

## Structure
- `Observation/PDFs/`: observation PDFs
- `E-Record/PDFs/`: e-record PDFs
- `Assignments/Assignment-1/`: Assignment 1 materials
- `Assignments/Assignment-2-Individual-Project/`: SkillSwap individual project
- `Group-Project/`: group client/server source

## Run SkillSwap
```powershell
cd Assignments/Assignment-2-Individual-Project
npm install
npm run dev
```
Open the local URL printed by Vite.
