# SkillSwap | Student Skill Exchange

## Overview
SkillSwap helps students learn from one another by exchanging skills instead of money. A student can publish an **Offering** (something they can teach) or a **Looking for** post (something they want to learn).

## Features
- Dashboard metrics for active posts, skill offers, and learning requests
- Browse skill listings with category and post-type filters
- Search by skill, title, or student name
- Add and delete listings
- Save interesting listings
- Data persists in browser `localStorage`
- Responsive layout for laptop and mobile screens

## Technology
React, Vite, JavaScript, CSS, localStorage. No backend is required for this frontend milestone.

## Run locally (Windows PowerShell)
```powershell
npm install
npm run dev
```
Open the URL shown by Vite, normally `http://localhost:5173`.

## Production build
```powershell
npm run build
```
